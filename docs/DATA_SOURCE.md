## V0.3 的 005 派生与导入

005 保留原规划的 1003 个 GCJ-02 顶点，以珍珠湾起点对应顶点为新首点循环移位，并复制新首点作为闭合点。结果为 1004 点、7 个 Waypoint。珍珠湾由独立起点 Marker 展示，沿线里程按新顺序计算。

在仓库根目录执行 node scripts/prepare-v03-route-release.cjs --out NEW_DIRECTORY。脚本离线校验六个 ID、Route/Import 对象一致性及轨迹索引，输出每条一份单行 .json（以换行结尾）以及单独的 manifest.json。仅将六份路线载荷导入有权管理的独立 routes_v03，保留 _id。manifest 用于核验，不作为路线导入。已验证的 routes_v03 无需重新导入或覆盖，旧 routes 供 V0.2 保留。发布包可用 node scripts/check-v03-route-release.cjs 离线检查。

原始GPX、私有来源清单、response、temporary、Seed/Mock、账号、个人GPS历史与未审日志/截图不在候选。只保留一个经审查的历史算法纯文本供B1负控制，不开放其他证据。地图服务归属及代码既有许可声明保留；未另授全部源码通用开源许可。
