# V0.3作品集演示指南

更新：2026-10-29。V0.2已公开；V0.3为内部候选。以下是可执行方案，不是本轮已完成的Android演示验收。

## 演示前检查

- 使用自己合法配置且已验证可读六路线的项目。公开源码含占位配置，不能现场直接导入即用；不要临时修改权限、关闭域名校验或借用他人云资源。
- 提前编译，确认首页→“探索徒步路线”→列表有005/006/008/009/010/011六条路线；详情绿色轨迹及节点正常。网络不可用时展示已审查的本机截图和源码，不把截图说成实时云读取。项目不提供离线地图。
- 面试默认不启动真实GPS。四条B1模拟不采集真实位置；008/010使用Native速览。先返回列表再换路线，不在清理失败时反复启动。
- 当前Access按所有者选择暂缓，accessRequestsEnabled=false；release真实GPS仍阻断。不要为了演示开放任何门。
- 截图入口：[既有真实截图及限制](SCREENSHOTS.md)。不要展示私人配置、Nearby地图、位置流或账号控制台。

## 常见现场问题及安全替代

|现场情况|处理|
|---|---|
|没有位置权限/拒绝授权|不重复请求；退出真实GPS测试，正常浏览及B1模拟仍可演示。不要在面试现场重置权限制造授权过程。|
|远离正式起点|接受“请到路线起点附近再开始循迹”等保护；首位置收到与following是不同结果。无需赶往起点或注入位置，改用模拟讲解。|
|精度较低、断流或疑似偏航|安全停稳后按实际状态结束；不能以良好单点证明稳定。不要故意进入危险区域验证偏航。|
|Access暂缓|展示卡片说明和“阅读隐私保护指引”；“同意并规划”不可用。返回后旧意图失效，不意味着同意过或自动请求。无需反复验证补充链接。|
|网络不稳定/云读取失败|使用页面“重新加载”或返回；仍失败就展示现有截图与测试证据，明确当前非实时读取。不能用硬编码数据冒充云端。|
|release与体验版不同|release阻断GPS是当前安全策略，不在现场改版本标识；体验版也须账号、权限和用户主动操作。|
|Native暂停稍有延迟|等当前短段结束；未确认停止不要切入GPS。出现清理错误时停止演示，保留脱敏提示。|

## 证据与限制的讲法

- SOURCE_VERIFIED：本轮核查正式页面入口、服务、B1及安全门；SIMULATED：既有本地测试和本轮页面回归。它们都不是Android实测。
- REPORT_VERIFIED / USER_REPORTED：R6H六路线正常页面、四模拟及两Native已获用户DevTools验收；R6K保留正式005 Android启动、首位置、起点保护和停止ACK。
- ANDROID_VERIFIED仅指历史用户提供的Android观察/脱敏摘要，不是Codex独立操作手机。Day4-D3 Nearby同路线连续会话有正向cursor证据和暂停恢复；实走估计约50米与cursor净增约10.50米不相等，未通过测距精度验收。
- FIELD_REQUIRED：正式路线following、可信推进、正式页暂停恢复、偏航/回归和终点仍缺现场证据。硬件GPS停止的独立系统证据UNKNOWN。不要把Nearby QA说成正式路线验收。
- 高德账号正常为USER_REPORTED；Day6-D3部署包/控制台只读核查不等于真实高德请求通过。真实Access按方案A暂缓，V0.3不是公开发布就绪。

私人报告留在本机归档，不作为公开素材自动纳入仓库。正式现场准备见[GPS验收手册](V03_GPS_FIELD_ACCEPTANCE_RUNBOOK.md)。
